Linear (Fixed-Effects) Model

  • In your previous courses, you have seen regression using ordinary least squares (OLS).

    • Given a set of \(k\) covariates \(X_{ij}\) and a continuous response \(Y_{ij}\) for \(i = 1, ..., n\), the OLS model we fit is:

      \[ Y_i = \beta_0 + \beta_1X_{i1} + \beta_2X_{i2} + ... + \beta_kX_{ik} \]

    • The parameters \(\beta_0, \beta_1, ... \beta_k\) are fixed and constant (i.e., they are the same for all observed values \(x_{i1}, ..., x_{ik}, y_{ik}\)

Linear (Fixed-Effects) Model

  • In the OLS linear regression model, we have a number of assumptions:

    • Linearity (there is a linear relationship)

    • Independence of residuals

    • Normality of residuals

    • Homoscedasticity (constant variance)

    • No multicolinearity

  • Today we will focus on settings where the independence assumption is violated.

Motivation for Mixed Effects Models

Mixed Effects Models cleverly handle:

  • nested structures (students could be sampled within classrooms, or patients within doctors/hospitals)
  • repeated measures
  • other correlations within groups that violate the independence assumption

This means:

  • Observations in our data set do not need to be independent

  • Your data can have subsets of elements share a correlation structure (e.g., repeated observations over time, clustered data)

    • In our grunfeld data set, we have repeated observations over time within a firm

Linear Mixed Effects Models (LMEM)

In the LMEM, we incorporate fixed and random effects.

  • Fixed effects are parameters that do not vary. These are what we estimate in a typical linear regression model using OLS.
  • Random effects are parameters that are themselves random variables. These have an assumed distribution.
    • We can have both random slopes and intercepts in these models

Linear Mixed Effects Models (LMEM)

LMEM model: \[ \boldsymbol{Y}_i = \boldsymbol{X}_i \boldsymbol{\beta} + \boldsymbol{Z}_i\boldsymbol{b}_i + \boldsymbol{\epsilon}_i, \]

such that

\[ \boldsymbol{Y}_i = \begin{bmatrix} Y_{i1} \\ Y_{i2} \\ \vdots \\ Y_{i,k_i}\\ \end{bmatrix} , \boldsymbol{X}_i = \begin{bmatrix} \boldsymbol{X}_{i1}^T\\ \boldsymbol{X}_{i2}^T \\ \vdots \\ \boldsymbol{X}_{i, k_i}^T\\ \end{bmatrix}, \boldsymbol{Z}_i = \begin{bmatrix} \boldsymbol{Z}_{i1}^T\\ \boldsymbol{Z}_{i2}^T \\ \vdots \\ \boldsymbol{Z}_{i, k_i}^T\\ \end{bmatrix}, \text{ and } \boldsymbol{\epsilon}_i = \begin{bmatrix} \epsilon_{i1}^T\\ \epsilon_{i2}^T\\ \vdots\\ \epsilon_{i,k_i}^T \end{bmatrix}, \] where

  • \(k_i\): the number of observations for subject \(i\), which may differ among subjects.
  • \(Y_{ij}\): the response of individual \(i\) at time \(j\),
  • \(\boldsymbol{X}_{ij}\): a \(p \times 1\) covariate vector for the fixed effects,
  • \(\boldsymbol{\beta}\): the vector of parameters for the fixed effects,
  • \(\boldsymbol{Z}_{ij}\): a \(q \times 1\) covariate vector for the random effects,
  • \(\boldsymbol{b}_{ij}\): a vector of parameters for the random effects, and
  • \(\epsilon_{ij}\): the random error associated with individual \(i\) at time \(j\).

Linear Mixed Effects Models: Random Intercepts

Let’s start with the simplest for of our LMEM and allow for a random intercept.

What does this mean? Our general model will be:

\[ Y_{ij} = X_{ij}\beta_{ij} + b_{i,0} + \epsilon_{ij}, \] where \(b_{i, 0}\) is the \(i\)th cluster/individual’s random intercept.


Relating this back to grunfeld, we could have a random intercept for each firm:

\[ \text{investment}_{ij} = \beta_0 + \beta_1 \text{market_value}_{ij} + \beta_2 \text{capital}_{ij} + b_{i,0} + \epsilon_{ij}, \]

where \(i = 1, 2, ..., 11\) is an individual firm (there are 11 in the data) and \(j= 1, 2, ..., n_{i}\) is the observation number from each firm (these vary for each firm!)

Linear Mixed Effects Models: Random Intercepts

\(b_{0, i}\) is a random effect which has a distribution. We assume:

\[ b_{0, i} \sim N(0, \sigma_0^2) \]

We also assume \(\epsilon_{ij} \sim N(0, \sigma^2)\), allowing for observations within a given firm to be correlated. We also assume that this error term is independent of any random effects.

Linear Mixed Effects Models: Random Intercepts

Let’s rearrange the LMEM:

\[ \text{investment}_{ij} = (\beta_0+b_{i,0}) + \beta_1 \text{market_value}_{ij} + \beta_2 \text{capital}_{ij} + \epsilon_{ij}, \]

Our “mixed intercept” is comprised of the overall fixed intercept (\(\beta_0\)) and a firm-specific random intercept (\(b_{i, 0}\)). That is, individual firms have unique intercepts that are offset from the overall average intercept.

So… how does this allow for correlated observations?

Well, the variance of the \(j\)th observation for the \(i\)th firm is:

\[ \text{Var}(\text{investment}_{i,j}) = \text{Var}(b_{i, 0}) + \text{Var}(\epsilon_{ij}) \] and within a single firm, we can show that the correlation is given by:

\[ \text{Corr}(\text{investment}_{i,k}, \text{investment}_{i, l}) = \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2} \]

Linear Mixed Effects Models: Random Slopes and Intercepts

In our previous visualizations, you could argue that the slopes of the individual firms also varied. We can add random effects for our covariates as well:

\[ \begin{aligned} \text{investment}_{ij} &= \beta_0 + \beta_1 \text{market_value}_{ij} + \beta_2 \text{capital}_{ij} +b_{i,0} + b_{i, 1}\text{market_value}_{ij} + b_{i, 2}\text{capital}_{ij} + \epsilon_{ij}, \\ &= (\beta_0 + b_{i,0}) + (\beta_1 + b_{i, 1}) \text{market_value}_{ij} + (\beta_2 + b_{i,2}) \text{capital}_{ij} + \epsilon_{ij} \end{aligned} \] Now we have mixed intercept and slopes that comprise of random and fixed effects!

What has changed in our model assumptions? Well, \(b_{i,0}, b_{i,1},\) and \(b_{i,2}\) follow a multivariate Gaussian distribution with \(d = 3\) and covariance matrix \(D\). More info here

Model Selection

We cannot simply determine if the random slopes should be included in the model by evaluating \(p\)-values from the model output.

Instead, we can perform a likelihood ratio test (LRT) to see if the model fit with the random slopes is more appropriate for this data (compared to the model without the slopes)

The null hypothesis for this test is that the simpler model is adequate.

We see the \(p\)-value is very small, indicating that we reject the null hypothesis that the simpler model is adequate (i.e., we should include the random slopes!)

Note: models must be nested and have the same fixed effects to do this test. You can compare the AIC or BIC to compare non-nested models.
